# World History Flipbook

A responsive, browser-based reader for **World History: Patterns of Interaction**. Open a PDF from your device to turn pages, search selectable text, zoom, and save a reading position.

## Privacy and book files

This site does not contain or upload the textbook. Each reader selects a PDF file from their own device; the browser reads it locally. The site author does not receive the file. Readers need their own authorized copy of the book. The book is a copyrighted work by McDougal Littell and is not included in this repository.

The app loads PDF.js and web fonts from their public CDNs, so an internet connection is needed. Reading position and bookmarks are stored in the reader's browser.

## Publish with GitHub Pages

1. Create a **public** repository named `world-history-flipbook` on GitHub.
2. Add the files in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, and save.
4. Once GitHub Pages finishes publishing, the site address will be `https://legendarygameryt66-wq.github.io/world-history-flipbook/`.

The repository is configured to allow search crawlers. Google can take days or weeks to discover a new site, and inclusion in search results is not guaranteed. To request indexing, verify the published site in Google Search Console and submit its URL for indexing.

## Local preview

Open `index.html` in a modern browser. An internet connection is needed for the viewer library and fonts.
